# 窗口管理

一个演示通过 [`DisplayServer`](https://docs.godotengine.org/en/latest/classes/class_displayserver.html) 提供的各种窗口管理功能的示例。

- 移动窗口。
- 设置窗口可调整大小/不可调整大小并设置其大小。
- 最小化和最大化。
- 在屏幕上移动窗口。
- 使窗口透明。
- 捕获、隐藏或限制鼠标。
- 获取有关屏幕的各种信息，包括 DPI 和刷新率。

语言：GDScript

渲染器：Compatibility

在资源库中查看此演示：https://godotengine.org/asset-library/asset/2791

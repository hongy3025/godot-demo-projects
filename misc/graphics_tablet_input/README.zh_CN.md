# 绘图板输入

一个演示如何在 Godot 中使用绘图板输入的示例。Godot 完全支持压力灵敏度、倾斜和笔反转（即检测笔上的"橡皮擦"是否正在使用）。请注意，某些平台和绘图板可能不支持倾斜报告。

此演示默认禁用了输入累积和垂直同步，以最大程度减少输入延迟并获得清晰的线条（即使在低 FPS 下）。这提供了尽可能灵敏的绘图体验。你可以在侧边栏中切换它们以查看效果差异。请注意，在 Android、iOS 和 Web 平台上，垂直同步在系统级别被强制启用，无法禁用。

线条使用 Line2D 节点绘制。每次你抬起笔并开始绘制新线条时，都会创建一个新的 Line2D 节点。通过在项目设置中启用 2D MSAA 来提供线条抗锯齿功能。

在此演示中也可以使用鼠标输入进行绘制，但建议使用绘图板。

> [!NOTE]
>
> 如果在 Windows 上遇到问题，请尝试在项目设置中将绘图板驱动程序从默认的 **winink** 更改为 **wintab**。同时，尝试将绘图板的输入模式从相对模式更改为绝对模式。

语言：GDScript

渲染器：Mobile

# 合成器效果（后处理）

此演示展示了如何使用合成器效果创建后处理。
此功能仅适用于基于渲染设备的渲染器，例如 Forward+ 渲染器。

语言：GDScript

渲染器：Forward+

> 注意：此演示需要 Godot 4.3 或更高版本

## 技术说明

此演示展示了使用新的合成器效果系统添加基于计算着色器的后处理。
合成器效果首先需要作为 `CompositorEffect` 资源的子类实现。
然后可以将此资源的实例添加到 `Compositor` 中，
既可以作为 `WorldEnvironment` 节点的一部分，也可以作为 `Camera3D` 节点的一部分。

在视口渲染期间，此资源上的 `_render_callback` 将在配置的阶段被调用，
并且可以提交额外的渲染命令。

此项目中的两个示例都添加了一个计算调用来应用全屏效果。
两者都设计为工具脚本，因此在编辑器和运行时均可工作。

`post_process_shader.gd` 展示了一个示例，其中使用模板着色器，将用户代码注入其中。
用户代码存储在合成器效果的属性中。
这种方法能够在属性在运行时更改时重新编译着色器。
这种方法无法有效利用着色器缓存，并且可能在某些平台上不受支持，
例如某些需要预编译着色器的游戏主机。

`post_process_grayscale.gd` 展示了一个示例，其中着色器代码存储在文件中，
即 `post_process_grayscale.glsl`，并在初始化时编译。
对于编辑项目来说，这意味着着色器在效果加载时编译一次。
修改 `glsl` 文件需要重新加载场景。
这种方法的优点是 Godot 可以预编译 `glsl` 文件。

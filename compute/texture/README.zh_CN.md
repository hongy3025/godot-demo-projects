# 计算纹理

此演示展示了如何使用计算着色器填充纹理，并将其用作材质着色器的输入。

当鼠标光标未悬停在平面上方时，会随机添加"水滴"来驱动波纹效果。
当鼠标光标位于平面上方时，您可以在平面上"绘制"来驱动波纹效果。

语言：GDScript

渲染器：Forward+

在资源库中查看此演示：https://godotengine.org/asset-library/asset/2764

> 注意：此演示需要 Godot 4.2 或更高版本

## 技术说明

由计算着色器填充的纹理包含高度数据，材质着色器使用这些数据来创建水滴/水波纹效果。这是一种自 90 年代中期以来就广为人知的技术，现已适配为计算着色器。

直接在渲染设备上创建了三个纹理：
- 一个纹理用于写入高度图并供材质着色器使用。
- 一个纹理用于读取，包含上一帧的数据。
- 一个纹理用于读取，包含前一帧的数据。

我们不是通过纹理到纹理的复制来创建这些历史数据，而是简单地循环使用 RID。

请注意，在此演示中，我们使用主渲染设备来确保在正常渲染之前执行计算着色器。

为了使用包含最新高度数据的纹理，我们使用了 `Texture2DRD` 资源，这是一种特殊的纹理资源节点，能够使用直接在渲染设备上创建的纹理，并将其暴露给材质着色器。

材质着色器使用标准的渐变方法，通过采样高度图并计算切线和副法线向量来调整法线。

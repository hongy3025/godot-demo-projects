# Pong 多人游戏（C#）

一个 Pong 的多人游戏示例。一个玩家按下"主机"。
另一个玩家按下"加入"。这仅在本地有效。

语言：[C#](https://docs.godotengine.org/en/latest/tutorials/scripting/c_sharp/index.html)

渲染器：Compatibility

注意：GDScript 版本可在此处获取：[链接](https://github.com/godotengine/godot-demo-projects/tree/master/networking/multiplayer_pong)。

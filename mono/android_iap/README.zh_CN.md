# Android 应用内购买（C#）

本示例演示如何使用 C# 在 Android 中实现应用内支付。

注意：运行此示例需要将游戏导出并上传到 Google Play。

语言：[C#](https://docs.godotengine.org/en/latest/tutorials/scripting/c_sharp/index.html)

渲染器：Compatibility

注意：GDScript 版本可在此处获取
[链接](https://github.com/godotengine/godot-demo-projects/tree/master/mobile/android_iap)。

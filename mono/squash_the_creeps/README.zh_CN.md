# Squash the Creeps（3D）

这是一个简单的游戏，你的角色必须移动和跳跃，尽可能多地压扁敌人。
每压扁一个敌人获得 1 分。

操作方式：

- <kbd>上箭头</kbd>、<kbd>W</kbd>、<kbd>手柄左摇杆</kbd>：向上移动
- <kbd>下箭头</kbd>、<kbd>S</kbd>、<kbd>手柄左摇杆</kbd>：向下移动
- <kbd>左箭头</kbd>、<kbd>手柄左摇杆</kbd>：向左移动
- <kbd>右箭头</kbd>、<kbd>手柄左摇杆</kbd>：向右移动
- <kbd>空格</kbd>、<kbd>鼠标右键</kbd>、<kbd>手柄 A/交叉键</kbd>：跳跃

这是文档中 ["你的第一个 3D 游戏"](https://docs.godotengine.org/en/latest/getting_started/first_3d_game/index.html)
教程所展示游戏的完成版本。更多详情请参考文档中的教程。

本示例涵盖：

- 处理玩家输入。
- 在 3D 游戏中移动和跳跃。
- 在游戏场地周围随机生成敌人。
- 使用内置动画编辑器为游戏注入活力。
- 创建完整的游戏循环，包括失败条件、分数和重新开始功能。

语言：C#

渲染器：Forward+

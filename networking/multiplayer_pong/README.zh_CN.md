# Pong 多人游戏

经典乒乓球游戏的多人实现。
其中一名玩家应按下**主机**，另一名玩家
输入主机的 IP 地址并按下**加入**。

语言：GDScript

渲染器：Compatibility

注意：非多人版本可在此处获取：[链接](https://github.com/godotengine/godot-demo-projects/tree/master/2d/pong)。

在资源库中查看此示例：https://godotengine.org/asset-library/asset/2798

# 保存与加载（序列化）

此演示展示了如何使用 Godot 支持的每种序列化格式保存简单游戏：

- ConfigFile
- JSON

未来可能会添加更多格式。

更多信息请参阅文档中的[保存游戏](https://docs.godotengine.org/en/latest/tutorials/io/saving_games.html)。

有关在导出项目中加载各种文件类型而无需导入的示例，请参阅[运行时文件保存与加载](../runtime_save_load/)演示。

语言：GDScript

渲染器：Compatibility

在资源库中查看此演示：https://godotengine.org/asset-library/asset/2781

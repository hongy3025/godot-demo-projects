# 躲避小怪

这是一个简单的游戏，你的角色必须移动并尽可能长时间地躲避敌人。

这是文档中["你的第一个 2D 游戏"](https://docs.godotengine.org/en/latest/getting_started/first_2d_game/index.html)教程所展示的游戏的完成版本。更多详情请参考文档中的教程。

语言：GDScript

渲染器：Compatibility

> [!NOTE]
>
> 此处提供 C# 版本：https://github.com/godotengine/godot-demo-projects/tree/master/mono/dodge_the_creeps

在资源库中查看此演示：https://godotengine.org/asset-library/asset/2712

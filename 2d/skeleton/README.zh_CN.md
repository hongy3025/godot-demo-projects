# Skeleton2D 演示

本演示展示如何使用 Godot 的 Skeleton2D 节点在 2D 中创建装配和动画角色。包含多个与运动相关的动画，以及一个控制动画的简单角色控制器。

语言：GDScript

渲染器：Compatibility

在资源库中查看此演示：https://godotengine.org/asset-library/asset/2731

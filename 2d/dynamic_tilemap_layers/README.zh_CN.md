# 动态 TileMap 图层

演示如何使用 TileMap 的 `_tile_data_runtime_update()` 方法制作假墙。展示如何按图层禁用碰撞。

语言：GDScript

渲染器：Compatibility

在资源库中查看此演示：https://godotengine.org/asset-library/asset/2713

## 注意

Godot 4.3 引入的新 TileMapLayer 允许在检查器中通过复选框动态禁用图层的碰撞。对于早期版本的 Godot，请使用此处描述的方法。

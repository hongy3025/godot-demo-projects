# 控件画廊

展示各种 Control 节点，并附有其名称以便于识别。
此演示的灵感来源于 GTK 等 GUI 工具包中类似的"控件画廊"演示。

3 个主面板（"基本控件"、"数字"和"列表"）
使用 HSplitContainer 和 VSplitContainer 节点分隔。
这使得它们各自的大小可以调整。拖动面板之间的空白区域
即可调整大小。

语言：GDScript

渲染器：Compatibility

在资源库中查看此演示：https://godotengine.org/asset-library/asset/2766

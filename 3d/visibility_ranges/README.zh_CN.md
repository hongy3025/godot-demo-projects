# 可见性范围 (HLOD)

此演示展示了如何使用可见性范围设置分层 LOD 系统。

这可以通过减少每帧必须绘制的绘制调用和多边形数量，显著提高 3D 场景的性能。

使用 WASD 或方向键移动，使用鼠标环顾四周。按 <kbd>L</kbd> 切换可见性范围的使用。按 <kbd>F</kbd> 将淡出模式在*透明度*（此演示中的默认值）和*滞后*（稍快，但会导致更突兀的过渡）之间切换。

> **注意**
>
> 禁用可见性范围后，性能预计会显著下降，因为所有树木无论距离远近都将以完整细节绘制。

语言：GDScript

渲染器：Forward Plus

## 工作原理

使用可见性范围提高性能有 2 个目标：

- 减少需要绘制的多边形数量。
- 减少绘制调用数量，同时在近距离时保留剔除机会。

为实现此目标，演示为每 16 棵树的集群包含四个 LOD 级别。以下是从最近到最远显示的级别：

- 单棵树，高几何细节。
- 单棵树，低几何细节。
- 树集群，高几何细节。
- 树集群，低几何细节。

当摄像机与树原点之间的距离大于 20 个单位时，高细节树混合为低细节树（过渡期持续 5 个单位）。

当摄像机与树原点之间的距离大于 150 个单位时，集群中的所有低细节树被隐藏，树木混合为高细节树集群。此过渡期持续较长的距离（50 个单位），因为这些 LOD 级别之间的视觉差异更大。

当摄像机与集群原点之间的距离大于 450 个单位时，高细节树集群混合为低细节树集群（过渡期也为 50 个单位）。

当摄像机与集群原点之间的距离大于 1,900 个单位时，低细节树集群以 100 个单位的过渡期淡出。在此距离下，场景中存在的雾使此过渡更难被注意到。

有几种方法可以进一步改进此 LOD 系统：

- 使用 MultiMeshInstance3D 在单个绘制调用中绘制几何体集群。但是，单个网格将无法从视锥体或遮挡剔除中受益（只有整个集群被一次性剔除）。因此，必须谨慎操作以平衡绘制调用数量与剔除效率。
- 在远处使用冒名顶替精灵。这些可以使用 Sprite3D 绘制，或者使用启用了公告板功能的 MeshInstance3D + QuadMesh 配合 StandardMaterial3D 绘制。

## 1. 项目概述

项目名：**Physical Light and Camera Units**（`project.godot` 中 `config/name`）

展示物理光照和摄像机单位的设置，允许使用真实世界单位（流明、勒克斯、开尔文、快门速度、光圈、ISO）。

主场景：`test.tscn`

## 2. 快速上手

通过 UI 面板调整光照和摄像机参数，实时观察场景变化。

## 3. 核心架构

```
test.tscn
├── WorldEnvironment
├── DirectionalLight3D
├── Camera3D
├── 3D 场景物体
└── UI (Control)              ← 参数控制面板
```

## 4. 文件逐层导读

### `options.gd` — 参数控制脚本

**关键设置：**

| 设置 | 说明 |
|------|------|
| 光照强度 | 流明 (lm) / 勒克斯 (lx) |
| 色温 | 开尔文 (K) |
| 快门速度 | 模拟摄像机快门速度 |
| 光圈 | F 值 |
| ISO 感光度 | 感光度 |

### 物理单位启用

在 `project.godot` 中启用：
```ini
[rendering]
lights_and_shadows/use_physical_light_units=true
```

### 物理单位 vs 任意单位

| 特性 | 任意单位（默认） | 物理单位 |
|------|----------------|---------|
| 易用性 | 开箱即用 | 需要参考真实世界数据 |
| 真实感 | 一般 | 高（照片级） |
| 调整难度 | 凭感觉 | 有真实参考 |

> 参考网站：https://physicallybased.info/

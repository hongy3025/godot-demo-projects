# 遮挡剔除和网格 LOD

此演示展示了在 3D 场景中使用遮挡剔除和网格细节级别。

演示包含 1,024 个相同的房间，排列在 64×64 的网格中。房间几何体
用作烘焙 OccluderInstance3D 的基础，允许每个房间在
被另一个房间的墙壁遮挡时被剔除。

遮挡剔除可以在受绘制调用限制的场景中提供性能优势。
然而，由于 Forward+ 后端使用深度预 pass，
着色成本已经通过深度预 pass 降低。因此，遮挡剔除
并不总是能带来明显的性能提升，尤其是在
遮挡剔除机会较少的室外场景中。没有 DirectionalLight3D 投射阴影的室内场景
是遮挡剔除的最佳场景。

蓝色球体利用自动生成的 LOD，减少了 GPU
每帧需要渲染的三角形数量。这在具有复杂几何体的场景中
提供了显著的性能提升。在大多数场景中，与遮挡剔除相比，
这提供了更大的性能优势。

在运行演示时，你可以切换网格 LOD 和遮挡剔除的使用，
以查看这些功能在此项目中带来的性能差异。结果
将根据你的 CPU 和 GPU 型号而有所不同。

> **警告**
>
> 如果你使用的是未完全优化的引擎构建，你可能会注意到
> 启用遮挡剔除会降低性能。这是因为
> 遮挡剔除对 CPU 来说是一个要求很高的过程，它需要所有
> 能获得的构建时优化。
>
> 官方构建是经过完全优化的，但自行编译的构建默认未完全优化
> （请使用 `optimize=speed use_lto=yes` SCons 选项）。

语言：GDScript

渲染器：Forward+

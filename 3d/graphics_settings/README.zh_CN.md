# 3D 图形设置

一个展示图形设置菜单示例的演示。

包含的设置如下：

**视频设置：**

- UI 缩放。
- 分辨率缩放。
- 显示滤镜（双线性、AMD FidelityFX Super Resolution 1.0 或 2.2）。
- 全屏。
- 垂直同步（传统和自适应）。
- 抗锯齿（MSAA、FXAA、SMAA、TAA）。
- 摄像机视野。

**效果设置：**

- 有符号距离场全局光照 (SDFGI)。
- 泛光（辉光）。
- 屏幕空间环境光遮蔽 (SSAO)。
- 屏幕空间反射 (SSR)。
- 屏幕空间间接光照 (SSIL)。
- 体积雾。
- 屏幕调整：亮度、对比度、饱和度。

语言：GDScript

渲染器：Forward+

在资源库中查看此演示：https://godotengine.org/asset-library/asset/2738

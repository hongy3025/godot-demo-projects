# 3D 光照和阴影

该项目展示了 Godot 支持的各种 3D 光照和阴影功能。
包括接触硬化阴影 (PCSS)、光照投影仪和区域光。

背景天空使用 PhysicalSkyMaterial，允许天空颜色
随着太阳执行昼夜循环而自动调整。辐射度贴图
（用于为场景提供环境光和反射光）会实时更新，
环境天空的处理模式相应设置。

语言：GDScript

渲染器：Forward+

在资源库中查看此演示：https://godotengine.org/asset-library/asset/2741

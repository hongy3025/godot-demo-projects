# 3D 航点

这是一个在 3D 世界中显示 GUI 元素（如标签）的示例，
通过将 3D 位置投影到屏幕上并直接显示 GUI 元素，
而不是依赖视口。这为显示玩家名称等用例提供了更好的可读性
和性能。

演示中展示的一些航点还会在玩家视野之外时
吸附到窗口边框。

此演示中未使用 Viewport 或 Sprite3D 节点。

语言：GDScript

渲染器：Forward+

在资源库中查看此演示：https://godotengine.org/asset-library/asset/2756

## 1. 项目概述

项目名：**3D Particles**（`project.godot` 中 `config/name`）

展示 Godot 支持的各种 3D 粒子功能，包括基于 GPU 和 CPU 的粒子，以及粒子碰撞、吸引器、拖尾和子发射器。

主场景：`test.tscn`

## 2. 快速上手

左右箭头键切换不同的粒子效果示例。鼠标拖拽旋转视角，滚轮缩放。

## 3. 核心架构

```
test.tscn
├── Testers (Node3D)          ← 多个粒子测试对象
├── CameraHolder (Node3D)
│   └── RotationX (Node3D)
│       └── Camera3D
└── UI (Control)
```

## 4. 文件逐层导读

### `tester.gd` — 主控脚本

与抗锯齿演示相同的测试浏览模式。

### 粒子系统类型

| 类型 | 节点 | 说明 |
|------|------|------|
| GPU 粒子 | `GpuParticles3D` | 大量粒子，性能更好 |
| CPU 粒子 | `CpuParticles3D` | 更灵活，支持碰撞 |

### 粒子功能展示

| 功能 | 说明 |
|------|------|
| 粒子碰撞 | 粒子与场景物体碰撞 |
| 吸引器 | 粒子被吸引到特定位置 |
| 拖尾 | 粒子运动轨迹拖尾效果 |
| 子发射器 | 粒子死亡时发射子粒子 |
| 发射形状 | 球形、锥形、盒子等发射区域 |
| 颜色渐变 | 粒子生命周期内颜色变化 |

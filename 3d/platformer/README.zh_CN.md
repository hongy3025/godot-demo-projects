# 平台游戏 3D

使用 [`CharacterBody3D`](https://docs.godotengine.org/en/latest/classes/class_characterbody3d.html)
的 3D 平台游戏演示。它使用与 2D 平台游戏类似的代码，但在 3D 中实现。

语言：GDScript

渲染器：Forward+

在资源库中查看此演示：https://godotengine.org/asset-library/asset/2748

此项目使用由 [`Marco F`](https://github.com/MarcoFazioRandom) 开发的虚拟摇杆插件实现触摸屏输入。
查看详情：https://godotengine.org/asset-library/asset/1787

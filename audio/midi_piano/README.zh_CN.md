# MIDI 钢琴

此演示展示了如何使用
[InputEventMIDI](https://docs.godotengine.org/en/latest/classes/class_inputeventmidi.html)
创建一个可由 MIDI 设备控制的钢琴。
已知可与 Yamaha MX88 配合使用。

钢琴也可以通过点击琴键来控制，或者手动调用每个琴键的 activate 和 deactivate 方法。

请注意，Godot 目前尚不支持 MIDI 输出，仅支持输入。

语言：GDScript

渲染器：Compatibility

在资源库中查看此演示：https://godotengine.org/asset-library/asset/2761

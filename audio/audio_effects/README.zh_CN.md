# 音频效果演示

这是一个简单的演示，展示了 Godot 中可使用的各种音频效果。
可以切换一个或多个音频效果，并将其应用于可播放的音效和背景音乐。

更多信息请参阅手册中的 [音频总线](https://docs.godotengine.org/en/stable/tutorials/audio/audio_buses.html)
和 [音频效果](https://docs.godotengine.org/en/stable/tutorials/audio/audio_effects.html)。

语言：GDScript

渲染器：Compatibility

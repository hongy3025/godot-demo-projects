# Godot 演示项目

每个包含 `project.godot` 文件的文件夹都是一个演示项目，用于
配合 [Godot Engine](https://godotengine.org)（开源
2D 和 3D 游戏引擎）使用。

## Godot 版本

- [`master`](https://github.com/godotengine/godot-demo-projects) 分支兼容 Godot 的 `master` 开发分支（下一个 4.x 版本）。
- [`3.x`](https://github.com/godotengine/godot-demo-projects/tree/3.x) 分支兼容 Godot 的 `3.x` 开发分支（下一个 3.x 版本）。
- 其他分支兼容对应的 Godot 稳定版本。
  - [点击此处](https://github.com/godotengine/godot-demo-projects/branches) 查看所有分支。
  - 例如，[`2.1`](https://github.com/godotengine/godot-demo-projects/tree/2.1)
    分支用于兼容 Godot 2.1.x 的演示项目。

## 导入所有演示项目

要在项目管理器中一次性导入所有演示项目：

- 克隆此仓库或[下载 ZIP 压缩包](https://github.com/godotengine/godot-demo-projects/archive/master.zip)。
  - 如果下载了 ZIP 压缩包，请将其解压到某个位置。
- 打开 Godot 项目管理器，点击右侧的 **Scan** 按钮。
- 选择包含所有演示项目的文件夹路径。
- 现在所有演示项目应出现在项目管理器中。

## 在浏览器中试用演示项目

大多数演示项目已导出到 GitHub Pages。您可以在
[此处](https://godotengine.github.io/godot-demo-projects/) 查看它们。

**注意：** Godot 在浏览器中的性能低于在桌面端原生运行。
为获得最佳性能，建议下载演示项目。

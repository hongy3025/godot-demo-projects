# OpenXR 透视演示

这是一个展示 OpenXR 透视功能的演示。

语言：GDScript

渲染器：Compatibility

> [!NOTE]
>
> 此演示需要 Godot 4.5 或更高版本

## 工作原理

透视是许多 XR 头戴设备上可用的功能。
它使用设备上的摄像头在头戴设备内部显示真实世界。

此演示展示了如何正确设置透视。
虽然演示会尝试以透视模式启动（参见 OpenXR 项目设置），
但还有额外的步骤需要执行，你可以在 `main.gd` 中找到。
最重要的是启用视口的透明背景功能。

请注意，环境也设置为使用天空进行环境色和反射，
即使在背景变为透明之后。
虽然不是本演示的一部分，
但这允许在支持此功能的头戴设备上进行精确的光照估计。

最后，还有一个使用 `shadow_to_opacity` 功能来切出
盒子形状的示例。
一个用例是允许用户将该盒子锚定在他们的键盘
所在位置，从而保持键盘对用户可见。
你只能在头戴设备中正确看到效果，因为编辑器视口不会
启用透明背景。

> [!IMPORTANT]
> 为了节省此仓库的空间，OpenXR Vendor 插件未包含在内，
> 但相关设置是本演示的一部分！
> 请先从资源库安装它。

## 动作映射

此演示项目有一个极简的动作映射，因为我们只处理定位。

## 在 PCVR 上运行

此项目可以像普通 PCVR 项目一样运行，但只有少数运行时实际以这种方式支持透视。
对于某些运行时，你仍然需要安装 OpenXR vendors 插件，因为透视支持可能依赖于供应商扩展。

确保已安装 OpenXR 运行时。

## 在独立 VR 上运行

此演示在独立头戴设备上效果最佳，因为许多设备支持透视。

你**必须**安装 Android 构建模板和 OpenXR vendors 插件。
此项目确实包含一个 `export_preset.cfg` 文件，其中包含一些此类设备的示例设置。
请按照[手册中关于部署到 Android 的说明](https://docs.godotengine.org/en/stable/tutorials/xr/deploying_to_android.html)操作。

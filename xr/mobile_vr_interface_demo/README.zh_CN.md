# 移动 VR 接口演示

这是一个非常简单的演示，展示了如何启用移动 VR 接口。
这是一个很好的小项目，可以在桌面上测试立体渲染，无需 XR 硬件。
在移动设备上使用时，可以测试简单的 3DOF 头部追踪。

语言：GDScript

渲染器：Compatibility, Mobile, Forward+

在资源库中查看此演示：https://godotengine.org/asset-library/asset/0000

## 工作原理

此示例展示了启用和测试 XR 应用程序的最简单形式。
它使用内置的移动 VR 接口。

在桌面上有简单的左/右/上/下移动。

## 不足之处

请注意，目前移动 VR 接口中的镜头畸变在兼容渲染器中**不**支持。
